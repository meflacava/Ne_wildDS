# Ne_wildDS
Code and files for wild Delta Smelt effective population size (Ne) using RADseq data

Raw, demultiplexed RAD sequencing data can be found on the NCBI Sequence Read Archive (BioProject PRJNA1112857; https://www.ncbi.nlm.nih.gov/sra).


abundance/ = abundance index by year

bioinformatics/ = scripts for data processing

BY1995-2020_MetadataForNeSamples_2025dec09.csv = sample metadata

ByGroup/ = files for temporal Ne

ByYear/ = files for LD Ne

ComboNe/ = files for combo B=Ne

Figures.R = code to generate figures

genotyping/ = code and bamlists for ANGSD locus discovery and genotyping

map/ = code and files to generate map

Ne_Nc_DeltaSmelt_2025nov14.csv = Ne output
